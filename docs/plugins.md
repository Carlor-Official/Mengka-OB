# 插件与指令规则

“插件管理”先选择机器人，再独立启停插件。默认关闭 Ping 插件，启用后对 `/ping` 回复可配置文本。

“指令规则”创建名称、触发词和回复内容。保存规则并不自动为所有 Bot 启用，需在插件管理中选择对应 Bot 开启。删除规则后停止执行，规则不会调用本机 Shell 或下载可执行文件。

Go 插件按 Bot 创建独立实例，通过优先级处理统一事件。事件先持久化，再异步交给插件；应使用 BotID 与事件 ID 保证业务幂等。静默模式保留事件记录，但不运行自动回复。

目前不支持直接上传运行官机云 Python 插件，也不兼容 NT 的 Node.js 托管包。需要将插件移植到 Go 接口，或在后续版本通过独立的进程适配层连接。请勿把这些插件包当作指令规则导入。
