# 更新完成提示确认

更新完成提示按更新任务 ID 确认。点击“知道了”、关闭按钮或其他正常关闭方式后，前端保存本地确认，并调用已认证的 `POST /api/v1/system/update/acknowledge`，请求体为 `{"id":"更新任务 ID"}`。

服务端只接受当前任务且状态为 `completed` 的确认，持久保存 `runtime-update.acknowledged`。重复确认幂等；旧任务、运行中和失败任务返回 409。原有版本、任务结果、更新时间和最低版本策略保留。下一次更新生成新 ID，仍会正常提醒。

前端读取旧版 sessionStorage 确认并迁移；localStorage 不可用时使用页面内状态与服务端确认。仅当前页面观察到运行中的任务变为完成，且确认已经持久保存后，才刷新前端资源。打开页面时读到历史完成结果，关闭提示不会再强制刷新。

验证包括：重复轮询、组件重新挂载、独立站点存储、旧版确认迁移、存储不可用、确认接口失败、异步确认与新任务竞争、鉴权、幂等与服务端重启恢复。完整升级需同时替换后端与 web/dist。
