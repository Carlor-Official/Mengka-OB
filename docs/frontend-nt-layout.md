# 正文页的 NT v2.6.0 布局基线

基线为 Mengka NT `v2.6.0`，原始前端提交 `39cfe72de5e367eef8099976d6518337c6eed44a`。本次只读取参考工作树；用于复用的节点页、账号页、插件页、按钮与插件样式均核对到该版本。

## 页面结构

| OB 页面 | NT 原版依据 | 实现 |
| --- | --- | --- |
| 模板、群组、用户、日志、订阅、任务、分享、聊天记录 | `views/admin/nodes/index.vue` | 标题与右侧操作、表格内工具栏、搜索、紧凑行、状态标签、行内操作及更多菜单 |
| 指令、欢迎、登录授权 | 同上及节点编辑弹窗 | 列表管理，逐条打开编辑弹窗；取消整页堆叠表单 |
| 分页 | `views/admin/account/index.vue` | 默认 50 条，超过一页才显示表格外的原版上一页/下一页操作 |
| 编辑与确认 | 节点/账号原版 Dialog | 圆角弹窗、左对齐标题、灰色填充输入框、底部原版提交按钮 |
| 插件服务 | `views/admin/plugins/index.vue` | 卡片标题与状态、右上更多菜单、中间指标区、令牌区和底部操作 |
| 插件导入 | `views/admin/plugin-market/index.vue` | 原版搜索、卡片摘要、能力指标、更多操作及文件选择区域 |
| 手机数据列表 | `nodes/index.vue` 的手机模板与样式 | 原版列表卡、信息网格和底部操作区 |

`NTDataTable.vue` 的手机样式来自上述节点页，`NTAccountFeatures.vue` 统一处理原生账号功能。业务字段和接口适配 OB；不接回 NT 的设备指纹、扫码登录或旧插件协议。

## 按钮与表单

普通页面使用原版 `components/ui/button`、`Input`、`Select`、`Switch`、`Checkbox`、`DropdownMenu` 和 `StatusBadge`。插件导入页使用原版专用 `PluginButton.vue`，加载 `styles/plugin-controls.css`，保持 44px 控件几何与原生反馈；不以普通按钮替代专用组件。

节点表单的填充输入框类名直接复用原版 `formControlClass`。正文不再使用自行拼出的多列大卡片、常驻聊天发送表单或整页规则编辑器；发送和修改进入对应原版弹窗。

## 验证

- 原版 UI 基础组件、样式文件和已有 Vue 样式块校验通过。
- 浏览器对比新列表与原版节点页的表头高度、字号和单元格间距，以及编辑输入框的高度、圆角和背景。
- 验证原版按下缩放 `0.98`、插件专用按钮 44px、分页、更多菜单和弹窗编辑。
- 桌面与 390px 手机布局截图检查；模板/规则/欢迎/登录授权保存及账号隔离保持有效。
- `scripts/verify-nt-body-ui.mjs` 是当前正文页流程验收；原有账号功能、控制台导航验收命令保留为此套件的入口别名。

## 机器人配置导入

`cmd/import-bots` 提供停机维护时的本地配置导入。它先校验完整批次，使用事务保存；已有 AppID 不覆盖，新账号默认停用，AppSecret 加密存储，主人信息不提升为控制台管理员权限。备份数据目录后运行：

```sh
go run ./cmd/import-bots -data data -config /private/path/bots.json
```

配置文件属于私密材料，不放入源码仓库。完成导入后按需要安全清理临时副本；原平台保持运行，回调切换属于独立操作。

0.7.3 已按产品要求删除 OB 的服务节点页面。文中 `nodes/index.vue` 仅指 NT v2.6.0 的视觉参考来源；保留复用的表格与手机列表样式，不再提供节点业务或接口。布局回归使用原版类名的独立测试夹具。
