# 0.7.1-dev 系统检视与优化

检视日期：2026-10-15。范围包含初始化与登录、账号管理、官方 WS/Webhook、事件队列、插件接入、控制台、统计接口、静态页面及前端请求生命周期。保留 NT v2.6.0 的 UI 基础组件、样式文件和已有样式块。

## 本次修复

| 问题 | 调整与验证 |
| --- | --- |
| 切换 Bot 留下上一账号的聊天文本、目标、回复 ID 和模板 | 一并清空草稿、详情和编辑窗口；浏览器验证新账号只显示自身模板 |
| 旧请求可能覆盖新账号内容，或在页面离开后启动轮询 | 统一可取消的读取请求，卸载后禁止重新启动；延迟响应与离页回归通过 |
| 普通数据列表每次额外读取模板和订阅 | 按页面需要读取；群组列表一次刷新由三个请求减至一个 |
| 插件列表失败只短暂提示，轮询错误被忽略 | 保留错误与重试入口；抑制重叠轮询；页面离开后停止请求 |
| 接口无默认等待上限 | 前端请求默认 30 秒，插件上传单独使用 120 秒；不自动重试消息发送 |
| 规则排序使用旧列表对象回写 | 移动刚读取的最新规则，保留服务端更新；浏览器验证修改后的回复不被覆盖 |
| 消息日志切换账号时被旧请求的忙碌状态阻挡 | 取消旧请求后立即加载新账号，后台隐藏时暂停轮询 |
| 账号发送条数一直为零、在线时间缺失、刷新顺序不稳定 | 返回实际成功发送计数与在线起点；批量聚合计数；按名称和 AppID 稳定排序 |
| 重复报告相同运行状态重置状态开始时间 | 仅状态或错误变化时更新起点，避免刷新在线时间 |
| 最近一分钟流量先聚合全部历史 | 时间区间下推到原始查询，使用部分索引；测试验证区间边界和索引搜索计划 |
| 账号日志与插件待处理事件缺少对应查询索引 | 增加匹配筛选条件的索引；不删除历史事件或业务数据 |
| 服务恢复页和更新提示页直接刷新返回 404 | 补齐 SPA 页面入口；应用 HTML 重新校验缓存；静态资源/API 未命中仍按原语义返回 |
| 端口冲突时仍先启动 Bot 和插件 | 在初始化运行服务前占用监听端口；测试验证占用时退出且未初始化管理员或工作进程 |

## 验证范围

- `go test ./...`、`go vet ./...`。
- 前端 159 项测试、138 个 Vue 文件绑定检查、生产构建。
- `scripts/verify-system-review.mjs`：多 Bot 切换、延迟响应、规则排序、读取失败恢复、离页轮询和端口冲突。
- 既有初始化、账号与品牌、后台管理、正文布局、插件服务浏览器回归。
- 原版 UI 基线检查：基础组件、样式文件及既有 Vue 样式块无变更。
- Windows 构建与 Linux amd64 交叉编译。交叉编译不代表已在 Linux 生产机运行验收。

测试使用临时数据库、虚构 Bot 和模拟网关。UI 验收包含桌面与 390px 手机尺寸。此轮未修改生产服务，未启用导入的生产 Bot。

## 尚未完成的接入验收

官方真实鉴权、实际收发、Webhook 公网 HTTPS 回调及长时间断线恢复仍需单独验收。完整回调地址的配置引导和集中的接入诊断仍未补齐。本轮优化不能替代这些接入工作。

当前仍按一个进程使用一个数据目录设计；端口冲突保护不等于数据目录的多进程锁。事件历史保留策略未调整，需按业务需求另行确定，避免清理破坏去重和统计。
