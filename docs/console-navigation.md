# 萌卡 OB 控制台入口

当前以 1.0.10-beta 为准，保留现有侧栏分组、键盘操作、页面标签及手机布局。

| 分组 | 入口 |
| --- | --- |
| 数据面板 | 框架运行概况 |
| 机器管理 | 账号列表、消息模板 |
| 数据管理 | 消息日志、群组管理、用户管理 |
| 运营管理 | 指令配置 |
| 聊天管理 | 会话记录、发送消息、撤回成功发送的消息 |
| 插件管理 | 插件导入、插件服务 |
| 系统设置 | 框架配置、接口调试、关于应用 |

## 自定义问答

IPC 账号的指令配置提供文字、图文、Markdown 编辑、预览、匹配方式、群聊/私聊范围、启停、排序与搜索。需要独立安装兼容的指令回复插件（cloud-command-handler 0.6.0 或以上），单独授权当前机器人，并提供图片上传权限。图文填写公开 HTTP(S) 图片链接，可附加文字。高级 API、随机回复和官方模板规则保留原配置，通过插件设置编辑。

页面复用通用插件服务的配置及暂停/恢复接口；保存时保留其他设置和权限。匹配规则、变量和回复执行仍位于插件，发行包不内置业务插件。非 IPC 账号保留原生兼容编辑器。

## 消息与联系人

消息模板支持原生 Markdown、官方模板、按钮和媒体参数。群组和用户从实际事件发现，不代表 QQ 的完整通讯录；可管理本地备注、标签和启用状态。消息日志支持关键词、时间范围与分批浏览。

聊天发送结果按官方返回显示已发送、发送失败或未确认。明确失败可查看原因并持久保存，网络超时和审核中保留未确认；已发送不表示对方已读。成功记录不会因之后删除好友或移出群而被改写为失败。无原始失败回执的历史不能可靠补判。

## 已移除的独立页面

1.0.10-beta 移除欢迎配置、分享链接、任务配置、订阅管理页面及对应导航和旧标签。旧欢迎、任务、订阅地址转至插件服务，旧分享地址转至账号列表。

本次仅移除控制台独立入口，保留已有数据和底层兼容接口；不停止插件内部的定时推送、欢迎或业务订阅。原订阅页面仅展示 QQ 官方授权订阅，不是 B站、X 等插件订阅列表，业务订阅仍由各自插件管理。
