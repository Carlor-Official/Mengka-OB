# 萌卡 OB v1.0.1-beta

## 新增

- 新增 `MENGKA_OB_LISTEN_HOST`，可单独限制监听网卡，不覆盖初始化保存的端口。

## 调整

- 部署修正版统一使用 v1.0.1-beta 版本号。
- 默认监听全部网卡的 TCP 18080，与 NT 默认部署方式保持一致；初始化保存的端口在重启后继续生效。
- 显式指定的 `-listen` 参数仍然优先，可按需要限制为本机访问。

## 修复

- 修复服务器部署后无法通过公网 IP＋端口访问的问题。
- 修复从其他目录启动时无法找到程序旁前端和数据目录的问题；保留旧工作目录中的数据，存在两份数据库时要求明确指定。
- 缺少前端文件时给出明确启动错误，避免空白页或在错误目录生成新配置。

## 优化

- 完善公网访问、端口放行、云安全组、防火墙及 systemd 部署说明，修正初始化默认端口提示。

## 升级说明

先备份整个 `data` 目录，通过在线更新或对应系统完整安装包升级。手动升级时停止程序后替换可执行文件与 `web/dist`，保留数据；不要复用 NT 数据目录或让多个进程共用同一份数据。

服务器管理页可通过 `http://服务器公网IP:18080` 访问，云安全组和防火墙需放行实际端口；官方 Webhook 回调仍需公网 HTTPS。旧版暂不升级时可显式使用 `-listen 0.0.0.0:18080`。若启动脚本仍写有 `-listen 127.0.0.1:18080`，新版会尊重该设置，公网直连需自行调整。

本版本沿用已有混淆和签名授权校验，不提高生产最低版本要求。Linux arm64 已完成交叉编译和架构检查，原生设备运行待验证。详见[部署指南](https://github.com/Carlor-Official/Mengka-OB/blob/main/docs/deployment.md)。
