# 萌卡 OB v1.0.2

## 新增

- 群聊新增“@全体成员”按钮，也可直接输入“@全体成员”。发送时自动转换，普通文字消息即可使用，不再要求搭配 Markdown。
- 消息模板、自定义按钮、卡片、回复内容以及标签、用户和群聊名单增加表单填写方式，无需自己拼写格式。
- Markdown 编辑增加常用排版按钮和变量插入，填写内容时可直接选择需要的名称。
- 官方接口工具增加中文字段名称、选项和分层填写方式；选择本地文件后可计算文件名、大小及校验信息，确认后才填入，不会自动上传或发送。
- 插件配置增加表单说明支持，插件作者可提供中文字段名称、选项、变量及默认值，由框架生成对应的填写界面。

## 调整

- 常用设置优先显示中文名称、选择框和可增删列表，减少需要填写代码的地方；原始内容及高级选项保留在可选的开发者模式中。
- 编辑消息、按钮和模板时保留现有内容；重置只针对当前选择的模板，并增加确认提示。
- 改善手机上的长表单和多层设置布局，方便查看、修改和保存。
- 官方接口仍按实际权限执行，失败时展示官方返回的状态、业务码和内容，并隐藏凭据；不会因超时自动重复发送。

## 修复

- 修复部分旧按钮格式在表单中读取、编辑后可能丢失结构或使用范围的问题。
- 修复仅修改一个字段时，其他字段中的未知内容、空值、开关、零值或原有类型可能被改写的问题；超出安全精度的数字保留原始内容。
- 修复切换消息格式或按钮模式时草稿可能丢失的问题，并支持恢复未提交的内容。
- 修复切换模板后插入链接仍使用旧位置的问题，以及在链接标题中按回车可能误提交整个表单的问题。
- 修复切换指令记录时可能残留上一条记录内容的问题。
- 修复文件读取、校验和重复选择时的状态竞争；取消、失败或较晚返回的结果不会静默覆盖当前内容，也不会误用上一份文件的信息。

## 升级说明

- 本版为纯框架更新。安装包仅包含框架程序、编译后的前端、说明和版本清单，不包含机器人配置、业务插件包、插件数据、订阅、数据库或管理员凭据。
- 升级前请备份，替换框架程序与整个 `web/dist`，保留自己的 `data` 目录及 `master.key`。不要用其他实例的数据覆盖现有数据，同一数据目录只能运行一个框架实例。
- 本次不会替换已安装的业务插件。新插件表单说明需要插件包提供；未提供说明的现用插件不会仅因升级框架就自动获得完整的中文专用表单。
- 从版本号高于 1.0.2 的历史 beta 或 migration 版本切换时，需要在停止旧实例后手动替换程序与前端；在线更新器不会把较低版本号当作更新。
- 支持 Windows amd64、Linux amd64 和 Linux arm64；Linux arm64仅提供交叉编译与架构检查。正式版仍无需注册卡或验证端账号，页面与框架运行时区保持东八区。
- 表单和接口工具的验证不代表每个 QQ 应用都具有全部接口权限；实际结果以官方返回为准。
