# 萌卡 OB v1.0.6-beta

## 修复

- 修复 Go 标准库证书校验漏洞 CVE-2026-111943（GO-2026-6809），拒绝包含已失去信任的中间证书的证书链，覆盖框架的 HTTPS 与 WSS 出站连接。

## 优化

- 三个平台的发布编译器统一升级并锁定为 Go 1.26.10，发布前检查编译器与 Garble 工具版本，防止使用旧工具链构建。
- 沿用现有字面量混淆、随机种子、符号剥离及算法签名授权校验。

## 升级说明

建议所有旧版本用户升级。该修复位于程序内的 Go 标准库，必须更新框架可执行文件并重启；仅更新前端或服务器安装的 Go 无法修复旧程序。

通过在线更新或对应系统完整安装包升级。手动升级前备份整个 `data` 目录（含 `master.key`），停止程序后同时替换可执行文件和 `web/dist`，保留原有数据。更新后刷新管理页面。

本版不提高生产最低版本要求。提供 Windows amd64、Linux amd64 和 Linux arm64 安装包；Linux arm64 已完成交叉编译与架构检查，未做原生设备运行验证。

详见[安全修复说明](https://github.com/Carlor-Official/Mengka-OB/blob/main/docs/security-cve-2026-111943.md)与[部署指南](https://github.com/Carlor-Official/Mengka-OB/blob/main/docs/deployment.md)。
