# 萌卡 OB v1.0.7-beta

## 新增

- 插件服务支持暂停执行并继续持久化接收事件，恢复后处理积压；支持按优先级消费事件及按服务设置动作速率。
- 增加仅限指定机器人使用的登录凭据及管理会话，机器人主人只能访问获授权账号和对应插件业务设置。
- 历史消息支持关键词、开始/结束时间及分批查询，联系人支持跨批搜索；历史保留时间可设置为永久。

## 修复

- 修复正常等待或接收回调的 Webhook 被统计为离线或正在登录的问题，账号状态和后续峰值采样采用统一的运行判定。
- 修复插件列表轮询时顺序跳动，状态更新不再移动卡片位置。
- 修复消息日志时间筛选在窄屏错位，以及侧栏键盘焦点框边缘被裁切的问题。
- 完善插件事件持久化、消费确认和重复确认处理，避免重复确认改变已消费事件的结果。

## 优化

- 重整插件服务卡片，名称与授权机器人分开展示，增加搜索、运行统计和明确的暂停配置提示；适配桌面、手机及深色模式。
- 数据面板区分 WebSocket 已连接与 Webhook 已启用，停用和接入异常仍单独保留。
- 保留 Go 1.26.10、安全校验及受保护构建；安装包增加前端静态文件白名单检查。

## 升级说明

通过在线更新或对应系统完整安装包升级。手动升级前备份整个 `data` 目录（含 `master.key`），停止程序后同时替换可执行文件和 `web/dist`，保留原有数据。更新后刷新管理页面。

本次发布仅包含框架程序、管理前端与说明文件，不附带机器人配置、业务插件包、插件数据、数据库、订阅、管理员账号或凭据。插件须由使用者独立导入和配置；框架更新不会自动迁入其他平台的机器人或插件。

插件“暂停执行”会继续收件；“停止服务”不再接收该服务的新投递。已有内置兼容功能保留，选择由 IPC 插件处理业务的账号应按插件文档配置，避免重复执行。Webhook 运行表示接收器已启用，不代表已经验证公网回调地址；账号页仍显示等待/已接收回调及最近回调时间。

本版不提高生产最低版本要求。提供 Windows amd64、Linux amd64 和 Linux arm64 安装包；Linux arm64 完成交叉编译及架构检查，未做原生设备运行验证。
