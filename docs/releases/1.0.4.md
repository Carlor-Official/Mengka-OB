# 萌卡 OB v1.0.4

## 新增

- 官方接口工具新增“用户资料”，填写用户编号即可查询官方提供的昵称、头像等资料。
- 接入官方消息事件新增的单聊昵称、头像及群内昵称，聊天和引用消息可显示对应群的成员昵称。
- 支持官方新增的群统一标识，保留关联信息，各机器人和群聊仍独立管理。
- 设置中的“框架与数据”新增“数据保留”，可分别选择聊天记录、问题排查记录、已完成任务内容和运行日志的保留时间。

## 调整

- 昵称自动补全接入新的官方用户资料接口，单聊用户和群成员分别使用对应的查询链路。
- 消息内容在加密保存前按需压缩，重复的插件事件内容共享保存；已有记录在后台分批处理，减少长期运行时的重复占用。
- 过期记录改为小批次清理，保留待处理任务、发送结果不确定的记录及防重复标识。
- 更新官方接口目录和中文填写说明，官方成功结果与错误内容继续直接展示。

## 修复

- 修复查询指令面板列表时漏传会话类型的问题，支持按单聊、群聊、文字子频道和频道私信查询。
- 修复群昵称可能跨群沿用，以及官方明确清空群昵称后仍显示旧值的问题。
- 修复资料查询较晚返回时可能覆盖新事件资料的问题。
- 修复群消息同时包含多种用户标识时的识别优先级，保留原有明确用户编号的兼容。
- 修复数据库维护与消息写入同时进行时可能出现的事务冲突，并完善大数据库整理的处理窗口。

## 升级说明

本版为纯框架更新，安装包仅包含程序、编译后的前端、说明和版本清单，不包含机器人配置、业务插件包、订阅、数据库或管理员凭据。正式版仍无需注册卡。

升级前请备份并停止旧实例，替换框架程序与整个 `web/dist`，保留自己的 `data` 目录和 `master.key`；同一数据目录只能运行一个框架实例。已安装的业务插件不会自动替换；需要使用新 SDK 字段的插件，应随各自插件包更新。

已保存的旧数据保留策略会继续沿用。新安装默认保留聊天记录和运行日志 30 天、问题排查记录和已完成任务内容 7 天；各项均可选择永久保留。缩短保留时间会删除超过期限的记录，操作前请确认备份。后台清理和压缩会逐步进行，不保证立即缩小数据库文件。

本版会写入新的压缩消息格式。升级后请勿直接降级到 v1.0.3 或更早版本，也不要用旧数据库覆盖升级后收到的新消息。

支持 Windows amd64、Linux amd64 和 Linux arm64；Linux arm64仅提供交叉编译与架构检查。
