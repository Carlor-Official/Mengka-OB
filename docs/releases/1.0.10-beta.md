# 萌卡 OB v1.0.10-beta

## 新增

- IPC 账号的指令配置支持自定义问答编辑：文字、图文、Markdown 三种回复模式，并提供触发条件、群聊/私聊范围、回复预览、搜索、排序及启停操作。
- 聊天消息保存发送结果和失败原因。被移出群聊、删除好友等明确的官方拒绝显示红色“发送失败”，可查看原因，刷新页面后仍保留。

## 调整

- 移除独立的欢迎配置、分享链接、任务配置及订阅管理页面和导航入口，自动过滤旧标签页，旧地址跳转至账号或插件服务。
- 页面入口调整不删除现有数据，不停用插件内部的欢迎、订阅和定时推送功能。

## 修复

- 区分发送成功、明确失败和结果未确认，网络超时、上游不确定响应及消息审核中不会误标为成功或明确失败。
- 手动发送与被动回复回退按一次逻辑发送记录最终结果，失败重试成功后更新同一条记录，避免重复气泡。
- 保留消息原位状态切换、输入焦点和平滑滚动；消息日志同步显示发送结果。

## 升级说明

通过在线更新或对应系统完整安装包升级。手动升级前备份整个 `data` 目录（含 `master.key`），停止程序后同时替换可执行文件和 `web/dist`，保留原有数据。此次包含发送结果存储变更，需要更新并重启框架，单独替换前端不足以完成升级。

自定义问答编辑器用于 `execution=ipc` 的账号，需独立安装兼容的指令回复插件（`cloud-command-handler` 0.6.0 或以上），单独授权当前机器人，并授予图片上传权限。图文使用公开 HTTP(S) 图片地址，可附加文字；实际 Markdown 发送取决于 QQ 应用权限。问答执行仍归插件，安装包不包含该插件。旧账号的原生配置兼容模式保留。

发送状态按该次官方接口结果判断，不会因为后来删除好友或移出群聊而把过去的成功消息改成失败。旧历史没有保存失败回执的，无法可靠补判；“已发送”不代表对方已读。

本版仅包含框架程序、管理前端与说明文件，不附带机器人配置、业务插件包、插件数据、数据库、订阅、管理员账号或凭据。首次启动需要自行初始化；业务插件须独立导入和配置。

沿用 Go 1.26.10、受保护构建及现有安全校验，不提高生产最低版本要求。提供 Windows amd64、Linux amd64 和 Linux arm64 安装包；Linux arm64 完成交叉编译及架构检查，未做原生设备运行验证。
