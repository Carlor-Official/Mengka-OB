# 萌卡 OB v1.0.9-beta

## 优化

- 分享消息使用独立卡片展示：标题与描述位于左侧、封面位于右侧、来源位于底部，整张卡片可打开链接。
- 分享卡片适配手机和深色模式，移除普通气泡的重复内边距，统一封面尺寸与卡片布局。
- 封面缺失或加载失败时显示固定占位，避免破图及加载过程中的高度跳动；来源图标与封面分别处理。

## 修复

- 完善文本摘要、`ark_data.fields`、ARK 对象及 JSON 分享卡片解析，保留安全的标题、来源、描述、封面与跳转链接。
- 修复空描述字段跨行读取后续字段的问题，拒绝脚本地址及含凭据的链接。
- 保留上一版聊天气泡发送进度、原位状态切换、输入焦点和阅读位置等优化。

## 升级说明

通过在线更新或对应系统完整安装包升级。手动升级前备份整个 `data` 目录（含 `master.key`），停止程序后同时替换可执行文件和 `web/dist`，保留原有数据。更新后刷新管理页面。

卡片封面取决于原始消息是否提供图片字段；上游未提供封面时显示占位，不会用发送者头像冒充封面。

本版仅包含框架程序、管理前端与说明文件，不附带机器人配置、业务插件包、插件数据、数据库、订阅、管理员账号或凭据。首次启动需要自行初始化；业务插件须独立导入和配置。

沿用 Go 1.26.10、受保护构建及现有安全校验，不提高生产最低版本要求。提供 Windows amd64、Linux amd64 和 Linux arm64 安装包；Linux arm64 完成交叉编译及架构检查，未做原生设备运行验证。
