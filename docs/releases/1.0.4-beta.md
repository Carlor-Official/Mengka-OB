# 萌卡 OB v1.0.4-beta

## 新增

- 聊天消息、撤回和昵称更新实时通知页面，断线重连自动补拉，保留定时补拉兜底。
- 会话列表新增“全部／群聊／私聊”筛选，可与搜索组合使用；新增未读及新消息提示，阅读历史时保留当前位置。
- 支持 Markdown 消息下方按钮的行列、文字和主次样式，安全链接可直接打开；需要 QQ 身份的回调与指令按钮提示在 QQ 客户端操作。
- 内置官方群成员昵称查询及可选 OIAPI 备用，带本地缓存、超时和失败退避。

## 修复

- 修复更新完成确认后反复弹窗，以及浏览器存储不可用时可能触发的刷新循环；新更新和失败提醒继续正常显示。
- 修复占位名称覆盖真实昵称的问题，兼容 `username`、`nickname` 和已有资料，不用空结果覆盖已有名称或人工备注。
- 修复仅在群内出现的成员被误列成私聊会话的问题。
- 好友添加等控制事件不再显示为空消息气泡，原始事件日志仍保留。

## 优化

- 提前缓存受支持的 QQ 图片，聊天图片与 Markdown 图片共用按机器人、消息隔离的读取接口。缓存加密保存并限制占用，补充过期、拒绝访问、网络、格式错误原因及重试入口。
- 完善宝塔/Nginx 的 Host、WebSocket 和 SSE 部署说明，避免反代将 Host 改成 localhost 导致登录拒绝及恢复页循环。

## 升级说明

通过在线更新或对应系统完整安装包升级。手动升级前备份整个 `data` 目录（含 `master.key`），停止程序后同时替换可执行文件和 `web/dist`，保留数据；不要只替换前端。更新后刷新管理页面。

昵称查询默认仅使用官方接口。缺少腾讯群成员查询权限时，可在“账号设置 → 昵称补查 → 昵称查询来源”选择“官方优先，OIAPI 备用”。备用查询仅向 `oiapi.net` 发送 AppID 和用户 OpenID，不发送 AppSecret 或聊天内容，只保存昵称；历史缺失资料后台分批查询，不保证每个 OpenID 都能返回名称。

已过期且从未缓存的旧图片无法恢复，需要重新发送。框架继续沿用 NT v2.6.0 外围组件和主题，以及 Garble 混淆、字面量保护、调试符号剥离和算法签名授权校验。安装包不含源码、管理员账号、机器人配置或数据库；本版本不提高生产最低版本要求。Linux arm64 已完成交叉编译和架构检查，未做原生设备运行验证。

详见[部署指南](https://github.com/Carlor-Official/Mengka-OB/blob/main/docs/deployment.md)、[实时聊天与昵称查询](https://github.com/Carlor-Official/Mengka-OB/blob/main/docs/chat-realtime-and-profiles.md)及[图片与按钮说明](https://github.com/Carlor-Official/Mengka-OB/blob/main/docs/chat-images-and-buttons.md)。
