# 萌卡OB 1.0.4beta

本版整合 1.0.3beta 之后的聊天显示、实时交互、昵称查询及更新提示修复，提供前后端完整安装包。

- **图片显示与缓存**：收到消息后提前缓存受支持的 QQ 图片；聊天图片、Markdown 图片共用按机器人和消息隔离的读取接口。补充过期、拒绝访问、网络及格式错误原因和重试入口。缓存内容加密保存并限制占用；已过期且从未缓存的旧图片无法恢复。
- **Markdown 按钮**：解析消息下方按钮的行列、文字和主次样式，尽量贴近 Windows QQ。安全链接可打开；需要 QQ 身份的回调或指令按钮提示在 QQ 客户端操作。
- **实时聊天**：收信、发信、撤回和昵称更新实时通知页面；断线重连自动补拉，保留定时补拉兜底。阅读历史时不强制跳到底部，新增未读与新消息提示。
- **会话筛选**：左侧支持“全部／群聊／私聊”，可与搜索组合使用。仅在群内出现、没有私聊记录的成员不会被误列成私聊会话；好友添加等控制事件不再显示为空消息气泡，原始日志仍保留。
- **昵称显示与补查**：修复占位名称覆盖真实昵称，兼容 `username`、`nickname` 和已有资料。内置官方群成员查询与可选 OIAPI 备用，带缓存、超时及失败退避，不用空结果覆盖已有名称或人工备注。
- **更新弹窗**：确认“更新完成”后持久保存，刷新、重新登录和重新打开页面不再反复提示；修复浏览器存储不可用时的刷新循环。新更新和失败提醒继续正常显示。
- **域名部署说明**：补充宝塔/Nginx 的 Host、WebSocket 与 SSE 配置，说明反代将 Host 改为 localhost 时造成的登录拒绝及恢复页循环。

## 安装与升级

提供 Windows amd64、Linux amd64、Linux arm64 完整安装包及 SHA256 校验文件。已有 beta 用户可通过框架内在线更新升级；手动升级请先备份整个 `data` 目录（含 `master.key`），停止旧程序后替换可执行文件和 `web/dist`，保留数据。不要只替换前端。更新后建议刷新浏览器。

昵称查询默认“仅官方接口”。若应用没有腾讯群成员资料查询权限，可在**账号设置 → 昵称补查 → 昵称查询来源**选择“官方优先，OIAPI 备用”。启用后仅向 `oiapi.net` 发送 AppID 和用户 OpenID，不发送 AppSecret 或聊天内容，只保存返回的昵称。历史缺失资料后台分批查询，不保证每个 OpenID 都能返回名称。

沿用 Garble 混淆、字面量保护、调试符号剥离及算法签名授权校验。发行包不包含源码、管理员账号、机器人配置或数据库。发布本身不提高生产最低版本门槛。

本版保持萌卡 NT v2.6.0 外围组件与主题。Linux ARM64 包经过交叉编译和架构检查，未做原生 ARM64 设备运行验证。
