# 萌卡 OB v1.0.5-beta

## 新增

- 支持按编号显示 QQ 内置小表情，并匹配已知的大表情名称；大表情资源可用时支持动画显示。
- Markdown、引用和合并转发中的表情共用同一套解析，支持减少动态效果设置。

## 调整

- 原生 Markdown 模板可使用聊天输入框的正文覆盖模板内容，留空则使用原模板正文。
- 官方参数模板保留原有模板 ID 和参数，聊天页提示在消息模板中修改正文，避免输入的文字被忽略。

## 修复

- 修复 QQ 小表情在聊天记录中仅显示文字名称的问题。
- 修复旧“文字＋按钮”模板按普通文本发送，导致 QQ 端只收到正文的问题；发送前规范为 Markdown 消息并保留完整按钮结构。
- 兼容简写的按钮行结构，主动发送转为被动回复时保留正文和按钮；发送记录与实际提交的消息体保持一致。
- 修复扩展表情图片地址未被识别为消息附件，导致同源图片读取失败的问题。

## 优化

- 表情资源由框架从腾讯资源地址读取并在本地缓存，限制下载并发、资源大小及缓存占用；小表情保持行内显示，大表情单独展示。
- 按钮结构不完整时在发送前给出明确提示，不改写已保存的模板。

## 升级说明

通过在线更新或对应系统完整安装包升级。手动升级前备份整个 `data` 目录（含 `master.key`），停止程序后同时替换可执行文件和 `web/dist`，保留原有数据；本版不能只更新前端。更新后刷新管理页面。

仅有名称、没有可识别编号或图片地址的未知自定义表情仍以文字显示。模板发送仍受机器人应用权限、按钮权限配置及 QQ 客户端支持情况影响；官方参数模板请在模板配置中修改参数。

本版沿用现有混淆及算法签名授权校验，不提高生产最低版本要求。提供 Windows amd64、Linux amd64 和 Linux arm64 安装包；Linux arm64 已完成交叉编译与架构检查，未做原生设备运行验证。

详见[部署指南](https://github.com/Carlor-Official/Mengka-OB/blob/main/docs/deployment.md)与[表情及模板发送说明](https://github.com/Carlor-Official/Mengka-OB/blob/main/docs/qq-faces-and-template-send.md)。
