# 萌卡 OB v1.0.11-beta

## 修复

- 修复进入聊天管理后再切换页面，导致内容区持续空白的问题。发送失败详情弹窗恢复到聊天页内部，页面离场动画能够正常完成；无需限制标签页数量。
- 保留发送中、发送失败原因、图片预览和聊天输入框的原位更新体验，支持连续切页、快速切页及浏览器前进后退。
- 包含插件请求的有界分片队列与期限处理：同一会话保序，慢请求不再阻塞心跳和事件确认；排队过期且尚未开始的请求不会延迟执行。

## 升级说明

可通过内测更新通道或对应系统安装包升级。手动升级前备份整个 `data` 目录（包括 `master.key`），停止程序后同时替换可执行文件和 `web/dist`，保留已有数据。不要覆盖或删除原有机器人配置、插件及插件数据。

业务插件的动态、直播和上舰通知去重属于独立插件更新，不包含在本次框架安装包内；仅升级框架不等同于升级业务插件。超时或结果未确认的发送不能视为未发送并盲目重试。

发行包仅包含框架程序、编译后的管理前端、版本清单和使用说明，不包含机器人配置、业务插件包、插件数据、数据库、订阅、管理员账号或凭据。首次使用需要自行初始化。

提供 Windows amd64、Linux amd64 和 Linux arm64 安装包，沿用 Go 1.26.10 及受保护构建。Linux arm64 进行交叉编译和架构检查，未做原生设备运行验证；不调整算法系统最低版本要求。
