# 萌卡 OB v1.0.1

## 新增与调整

- 对齐 QQ 官方接口，支持群管理、菜单与指令面板、Markdown 素材管理、媒体分片上传、单聊流式消息，以及频道成员、身份组、公告、日程、帖子、音频和消息表态。
- 补齐 102 个官方 HTTP 方法与路径组合，同步 API 调试目录和插件接口授权选项。
- 支持图文卡片消息、Markdown 图片转存校验与官方素材引用，保留新增事件字段。
- 官方调用失败时返回 HTTP 状态、原业务码、响应体及追踪信息，不预判 QQ 接口权限；仅隐藏访问令牌和 AppSecret。
- 框架运行、页面显示、聊天日期分隔、时间筛选、每日统计和新建任务统一使用东八区。已有任务显式设置的其他时区不变，历史 UTC 数据不改写。

## 修复

- 修复浏览器所在时区与服务端统计日界线不一致的问题。
- 修复流式消息及媒体上传直接发送时，连接中断或服务端异常未被识别为未知发送结果的问题。未知结果不会自动补发。
- 修复图文卡片在消息模板中被误当成文本或 Markdown 的问题。
- 更新 DOMPurify、markdown-it 与 follow-redirects 安全补丁。

## 升级说明

安装包只包含框架程序、编译前端、说明与版本清单，不包含机器人配置、业务插件、订阅或数据库。升级保留原 `data` 与 `master.key`，同一数据目录不要同时运行两个实例。B站、X等插件包不会随框架更新而替换。

历史版本号高于 1.0.1 的 beta 或迁移版需停机后手动替换程序与整个 `web/dist`；在线更新器不会将较低版本号识别为更新。

支持 Windows amd64、Linux amd64 和 Linux arm64，继续使用 Go 1.26.10 与 Garble 0.17.0 构建。
