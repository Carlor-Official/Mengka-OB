# 萌卡 OB v1.0.0-beta

## 新增

- 首个外发内测版，沿用萌卡 NT v2.6.0 的界面布局与按钮交互。
- 支持多个官方机器人独立配置 WebSocket 或 Webhook，提供回调地址预览和服务器出站 IP 提示。
- 支持正向 WS、反向 WS、IPC 插件服务与插件包导入，使用 OB 独立插件协议。
- 提供账号、消息、群组、用户、指令、欢迎、任务、订阅及系统设置管理。
- 接入 OB 独立算法账号和版本限制，支持一键重启、低版本强制更新、进度提示与失败重试。

## 优化

- 外发程序启用符号与字符串混淆，移除调试信息，保留签名授权和更新完整性校验。

## 升级说明

首次安装请按系统下载完整安装包，解压后运行程序，打开 `http://127.0.0.1:18080` 完成管理员初始化。本版本默认仅监听本机，服务器部署需配置 HTTPS 反向代理；每个部署使用独立的管理员、机器人配置和数据目录。

从 v0.9 或更早开发版升级，请先备份整个 `data` 目录，停止旧程序后替换可执行文件与 `web/dist`，保留原有数据。OB 插件使用独立协议，不直接兼容 NT 插件二进制；不要复用 NT 数据目录。

本版本订阅 beta 更新通道，支持后续 beta 和正式版更新，仍受 OB 独立授权及最低版本策略控制。发布本身不提高生产最低版本要求。

Windows 与 Linux amd64 已验证启动、重启及会话恢复；Linux arm64 已完成交叉编译与包结构检查，原生设备运行待验证。真实收发请按自己的开放平台权限和网络配置验收；反馈日志须脱敏，不要提交密码、AppSecret、令牌或数据库。
