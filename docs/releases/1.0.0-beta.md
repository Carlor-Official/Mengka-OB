# 萌卡OB 1.0.0beta

首个外发内测版，内部版本号为 `1.0.0-beta`。

- 沿用萌卡 NT v2.6.0 的界面与按钮交互，使用萌卡OB品牌。
- 多 Bot 独立配置官方 WebSocket 或 Webhook，显示回调地址预览和服务器出站 IP。
- 正向 WS、反向 WS、IPC 插件服务与插件包导入，使用 OB 新协议。
- 账号、消息、群组、用户、指令、欢迎、任务、订阅及系统设置集中管理。
- 独立 OB 算法账号和版本限制，支持一键重启、低版本强制更新、更新进度和失败重试。
- 外发程序使用 Go 符号与字符串混淆、去除调试信息，并保留签名授权和更新完整性校验。

## 安装

按系统下载一个压缩包并完整解压，Windows 运行 `mengka-ob.exe`，Linux 执行 `chmod +x mengka-ob && ./mengka-ob`。打开 `http://127.0.0.1:18080` 完成管理员初始化。详细说明随包附带于 `README.txt`。

默认仅监听本机；服务器部署请配置自己的 HTTPS 反向代理。每位测试用户使用独立的数据目录、管理员和官方机器人配置。

## 升级与内测范围

从 0.9 或更早开发版升级，请先备份并保留完整 `data` 目录，停止旧程序后替换可执行文件与 `web/dist`。不要使用 NT 的数据目录。

此版本订阅 beta 更新通道，可更新后续 beta 或正式版。框架业务受 OB 独立授权和最低版本策略控制；发布内测包不会自动提高生产最低版本。

Windows 与 Linux amd64 已验证实际启动、重启和会话恢复。Linux arm64 已完成交叉编译与包结构检查，原生设备运行仍待内测反馈。真实 QQ 收发请按自己的开放平台权限与网络配置验收。

插件采用 OB 新协议，不能直接导入 NT 插件二进制。反馈问题时请附版本、平台、重现步骤及已脱敏日志，不要上传密码、AppSecret、令牌或数据库。
