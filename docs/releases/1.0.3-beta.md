# 萌卡 OB v1.0.3-beta

## 新增

- 聊天工具栏新增发送格式选择，Markdown 模式支持桌面左右分屏、手机上下分屏的实时预览，与聊天记录共用渲染器。
- 支持 QQ 双下划线加粗、删除线和图片宽高标记，保留长图比例；QQ 专属指令显示为文字标签，实际操作在 QQ 客户端完成。

## 调整

- Markdown 模式使用 Enter 换行、Ctrl＋Enter 或按钮发送，发送后保留 Markdown 模式；切换账号或会话时清空草稿。
- 普通文字仍使用 Enter 发送、Shift＋Enter 换行，输入法组词期间不触发发送。

## 修复

- 修复纯图片消息首次加载时缩成 0×0，导致懒加载无法触发的问题。
- Markdown 按完整文档解析，保留标题、列表、引用、代码块、表格和图文结构，避免拆分图片破坏排版。

## 优化

- 对照 Windows QQ 调整 Markdown 卡片背景、字号、段落间距、代码、引用线和链接样式，框架外围继续使用 NT 原有主题与控件。
- 图片预留显示尺寸，补充加载提示、失败原因和重试入口；没有可展示内容时明确提示。

## 升级说明

通过在线更新或对应系统完整安装包升级，无需单独安装前端补丁。手动升级前备份整个 `data` 目录（含 `master.key`），停止程序后替换可执行文件与 `web/dist`，保留数据。安装过 v1.0.2-beta 前端补丁的用户也可直接升级，更新后按 Ctrl＋F5 刷新页面。

沿用 Garble 混淆、字面量保护、调试符号剥离及算法签名授权校验，安装包不包含源码、管理员账号、机器人配置或数据库。本版本不提高生产最低版本要求。

Markdown 样式按已验证的 Windows QQ 样本对齐，不同客户端、字体、缩放及主题可能存在差异。Linux arm64 已完成交叉编译和架构检查，原生设备运行待验证。详见[部署指南](https://github.com/Carlor-Official/Mengka-OB/blob/main/docs/deployment.md)与[Markdown 预览说明](https://github.com/Carlor-Official/Mengka-OB/blob/main/docs/markdown-preview.md)。
