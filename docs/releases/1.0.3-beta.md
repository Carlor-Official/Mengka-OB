# 萌卡OB 1.0.3beta

本版整合 1.0.2beta 发布后的图片显示修复、Windows QQ Markdown 样式调整和分屏实时预览，无需再单独安装前端补丁。

- 修复纯图片消息首次加载时缩成 0×0、懒加载无法触发的问题。图片预留显示尺寸，提供加载提示、失败原因及重试入口；没有可展示内容时明确提示。
- Markdown 按完整文档解析，保留标题、列表、引用、代码块、表格与图文结构，避免拆分图片破坏排版。
- 对照 Windows QQ 的同一条真实消息，调整局部卡片背景、字号、段落间距、代码、灰色引用线和蓝色链接；框架外围继续使用 NT 原有主题与控件。
- 支持 QQ 双下划线加粗、删除线及图片宽高标记，保留长图比例；QQ 专属指令显示为文字标签，实际指令需在 QQ 客户端执行。
- 聊天工具栏新增明确的“发送格式”选择。Markdown 模式提供桌面左右分屏、手机上下分屏的实时预览，预览与聊天记录共用同一渲染器。
- Markdown 模式 Enter 换行，Ctrl+Enter 或“发送 Markdown”按钮提交。发送后清空正文并保留 Markdown 模式；切换账号或会话时清空草稿。普通文字模式仍支持 Enter 发送、Shift+Enter 换行。

## 安装与升级

提供 Windows amd64、Linux amd64、Linux arm64 完整安装包及 SHA256 校验文件。安装包不包含管理员账号、机器人配置、数据库或源码。

已有用户可通过框架内在线更新升级。手动升级时，先备份整个 `data` 目录（包含 `master.key`），停止程序后替换可执行文件和 `web/dist`，保留数据。安装过 1.0.2beta 前端补丁的用户也可直接升级。更新后按 Ctrl+F5 刷新浏览器。

沿用 Garble 混淆、字面量保护、调试符号剥离及算法签名授权校验。本版继续使用 beta 通道，发布本身不提高生产最低版本门槛。

Windows QQ 的版本、字体、缩放和主题可能导致细微差异；目前按已验证的 Windows QQ 样本对齐，不承诺所有客户端逐像素一致。Linux ARM64 包经过交叉编译与架构检查，原生设备仍需内测反馈。
