# 萌卡 OB v1.0.0

## 新增

- 发布首个正式版，支持 Windows amd64、Linux amd64 和 Linux arm64。
- OB 可直接部署并初始化本地管理员，无需注册卡、验证端账号或设备登记。
- 验证端为萌卡 NT、萌卡 OB 分别管理发布源、版本启停和最低版本要求。

## 调整

- OB 与验证端仅同步匿名版本策略，不再申请账号授权或续期会话，不上传机器人、插件、消息及管理员凭据。
- 版本服务暂不可用时沿用已有策略；全新实例可继续初始化，已知停用限制不会因断网或重启解除。
- 安装包只包含框架、管理前端、说明及版本清单，业务插件需单独导入。

## 修复

- 修复进入聊天管理后连续切页出现空白的问题。
- 修复插件回执查询阻塞事件处理、影响机器人响应的问题。
- 聊天按真实结果显示发送中、已发送、发送失败或未确认，并保留失败原因。

## 优化

- 包含聊天发送衔接、发送按钮间距及分享卡片样式调整。
- 保留分片有界请求队列、执行期限和请求幂等，避免慢请求拖住心跳或事件确认。
- 图片发布支持内容复用、缓存额度和过期清理，减少重复内容占用。
- 三个平台使用 Go 1.26.10 与 Garble 0.17.0 构建，保留证书校验安全修复。

## 升级说明

正式版从 **1.0.0** 开始编号，历史 beta 及其附件保留。版本号高于 1.0.0 的 beta 用户请停止旧实例，手动替换框架程序和整个 `web/dist`，保留原 `data` 与 `master.key`；在线更新器不会将较低版本号识别为更新。升级前备份数据，不要让两个实例共用同一数据目录。

此前使用 `/ob-access` 授权适配的实例，应将 `MENGKA_OB_VERIFIER_URL` 改为 `https://qqsign.bilibilibot.com`，并移除 `MENGKA_OB_REGISTRATION_FILE`。新版不读取或上传旧身份设置，无需删除数据库。

B站、X等业务插件的通知去重与业务修复由独立插件提供，不包含在框架安装包中。Windows amd64 与 Linux amd64 已验证实际包启动、免卡初始化及重启；Linux arm64 仅完成交叉编译和架构检查。
