# 萌卡 OB v1.0.8-beta

## 优化

- 聊天发送进度移至消息气泡下方：发送时显示“发送中”和加载动画，成功后在原位置切换为“已发送”，右下角发送按钮保持稳定。
- 发送成功后仅增量合并当前会话记录，保留已有消息节点、输入焦点及阅读位置，减少发送前后的闪动和跳位。
- 新消息平滑衔接；向上阅读历史时不强制滚到底部，并遵循系统的“减少动态效果”设置。
- 输入框与发送按钮区增加间距，兼顾桌面和手机布局。
- 实时同步优先更新消息，联系人和模板按需补查，避免每次发送都重新加载整页资料。

## 修复

- 修复实时消息先于发送响应到达时可能出现的重复气泡，按官方消息 ID 对账并保留同一个气泡位置。
- 修复后台同步导致已展开的完整富消息被重置，以及延迟加载图片打断平滑滚动的问题。
- 发送失败保留草稿；结果未确认时显示“未确认”，重试沿用原请求标识，避免重复提交。
- 保留 Markdown 编辑模式，修复发送期间输入框失焦及消息区域尺寸变化的问题。

## 升级说明

通过在线更新或对应系统完整安装包升级。手动升级前备份整个 `data` 目录（含 `master.key`），停止程序后同时替换可执行文件和 `web/dist`，保留原有数据。更新后刷新管理页面。

本版仅包含框架程序、管理前端与说明文件，不附带机器人配置、业务插件包、插件数据、数据库、订阅、管理员账号或凭据。首次启动需要自行初始化；业务插件须独立导入和配置。

沿用 Go 1.26.10、受保护构建及现有安全校验，不提高生产最低版本要求。提供 Windows amd64、Linux amd64 和 Linux arm64 安装包；Linux arm64 完成交叉编译及架构检查，未做原生设备运行验证。
