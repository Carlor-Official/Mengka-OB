# 萌卡 OB v1.0.3

## 新增

- 图片消息新增独立的“复制图片链接”，支持电脑右键、手机长按及键盘操作。
- 多图、图文、Markdown和卡片可按实际选中的图片复制原图地址；无可用外链或复制失败时给出明确提示。

## 调整

- 群聊和私聊图片链接在 QQ 明确返回 `40093007`“富媒体文件下载失败”时，尝试由框架安全读取图片，再转为文件上传。只处理明确失败的图片准备阶段，不会因消息超时或结果不明而自动重发。
- 安全取图仅限公网地址，限制跳转、超时、大小及并发；兼容处理限 5 MiB 内 PNG/JPEG 图片。过期、需要登录或源站拒绝访问的链接仍可能失败。
- 图片错误保留官方状态、业务码、失败阶段和原始返回，并隐藏链接中的凭据；图片链接输入自动清理首尾空白。

## 修复

- 修复消息日志和插件日志直接显示 UTC、与其他页面相差八小时的问题，统一按东八区显示。已有时区偏移不会重复转换，数据库及消息正文保持不变。
- 修复图片菜单只有普通“复制”、无法独立复制图片链接的问题，以及多图片消息可能选错图片的问题。
- 修复普通 HTTP 环境下的图片链接复制兼容与失败反馈，避免误复制后台代理地址。

## 升级说明

- 本版是纯框架更新，安装包仅含程序、编译前端、说明和版本清单，不含机器人配置、业务插件或数据。
- 升级前备份并停止旧实例，替换框架程序与整个 `web/dist`，保留自己的 `data` 和 `master.key`；同一数据目录不能运行两套框架。
- 不自动升级已安装的业务插件。无需注册卡，沿用 OB 独立版本策略。
- 支持 Windows amd64、Linux amd64、Linux arm64；arm64仅做交叉编译和架构检查。图片兼容回归使用模拟官方响应，另有真实公网只读取图验证，不代表所有第三方图片链接均可发送。
