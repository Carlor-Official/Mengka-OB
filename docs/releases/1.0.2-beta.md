# 萌卡 OB v1.0.2-beta

## 新增

- 聊天管理采用会话列表、消息气泡和底部输入区，显示机器人及用户头像、昵称，支持文字、图片、Markdown 和消息模板。
- 支持右键或长按进行回复、复制和撤回；支持引用回复、多图、GIF、可展开的合并转发、语音播放及 SILK 解码。
- 分别保存完整原始事件和聊天展示内容，支持云平台完整事件转发，保留发送请求、返回结果、未知字段及长正文，原始记录保留 30 天。

## 调整

- 发送时优先使用主动消息，仅在官方明确拒绝主动消息权限后尝试被动回复；按机器人和会话管理消息序号及有效凭据。
- 账号列表补齐机器人头像并移除等级。Webhook 在线时长从用户启用登录时计算，WebSocket 按真实连接时长计算。

## 修复

- 修复 HTTP 公网 IP＋端口访问时，添加规则、剪贴板及相关交互无法使用的问题。
- 进入会话后独立读取最近 100 条记录，避免被其他繁忙会话挤出全局最近记录。

## 优化

- 发送失败显示具体原因，沿用同一请求标识重试，减少重复发送。
- 完善图片、音频和视频显示，保留脚本限制；官方只提供摘要、缺少附件地址或资源过期时给出明确提示。

## 升级说明

通过在线更新或对应系统完整安装包升级。升级前备份整个 `data` 目录（含 `master.key`）；手动升级时停止程序后替换可执行文件与 `web/dist`，保留数据。不要复用 NT 数据目录或让多个进程共用同一份数据。

首次使用自行初始化管理员账号。管理页支持公网 IP＋端口，官方 Webhook 回调仍需公网 HTTPS。文字输入 Enter 发送、Shift＋Enter 换行。

沿用 Garble 混淆、字面量保护、调试符号剥离和算法签名授权检查，安装包不包含源码、机器人配置、管理员凭据或数据库；混淆不等于无法逆向。本版本不提高生产最低版本要求。Linux arm64 已完成交叉编译和架构检查，原生设备运行待验证。

详见[部署指南](https://github.com/Carlor-Official/Mengka-OB/blob/main/docs/deployment.md)与[富消息说明](https://github.com/Carlor-Official/Mengka-OB/blob/main/docs/chat-rich-messages.md)。
