# 萌卡OB 1.0.2beta

本次内测版补齐可视化聊天和富消息展示，并修复公网 HTTP 访问时的交互问题。

- 聊天管理采用会话列表、消息气泡与底部输入区，显示机器人及用户头像、昵称。支持文字、图片、Markdown 和消息模板，Enter 发送、Shift + Enter 换行，右键或长按进行回复、复制与撤回。
- 发送优先使用主动消息，仅在官方明确拒绝主动权限时尝试被动回复；按 Bot 和会话管理消息序号与有效凭据，错误显示具体原因，避免重复发送。
- 支持引用回复、多图、GIF、可展开的合并转发、语音播放及 SILK 解码。官方只有摘要、缺少附件地址或资源过期时明确提示，不伪造完整内容。
- 完整原始 JSON 与聊天展示分别保存，未知字段和长正文不会被展示摘要覆盖。支持接收云平台完整事件转发，并保留发送请求及返回结果；原始记录跟随日志保留 30 天。
- 进入会话后独立读取最近 100 条记录，避免被其他繁忙会话挤出全局最近记录。
- 账号列表补齐机器人头像并移除等级；Webhook 时长按用户启用登录开始累计，WebSocket 按真实连接计算。
- 修复 HTTP 公网 IP＋端口下添加规则、剪贴板及相关交互兼容；允许聊天所需的图片、音频和视频来源，保留原有脚本限制。

## 安装与升级

提供 Windows amd64、Linux amd64、Linux arm64 三个完整安装包及 SHA256 校验文件。完整解压后启动，访问 `http://服务器公网IP:18080`；首次使用自行初始化管理员账号。官方 Webhook 回调仍需公网 HTTPS。

升级前备份整个 `data` 目录（包含 `master.key`）。可通过框架内在线更新，或停止程序后替换可执行文件与 `web/dist`，保留原有数据。请勿复用 NT 数据目录，也不要让多个进程同时使用同一份数据。

沿用现有 Garble 混淆、字面量保护、调试符号剥离和算法签名授权检查；发行包不含源码、机器人配置、管理员凭据或数据库。混淆不等于无法逆向。

本版通过 beta 更新通道发布，发布本身不会提高生产最低版本门槛。Linux ARM64 包经过交叉编译与架构检查，原生设备运行仍需内测反馈。
