# 萌卡 OB v1.0.5

## 新增

- 页面标签栏新增内容区域最大化与还原，可集中查看当前页面。
- 框架配置新增可视化主题颜色选择，支持八种主题色。
- 数据面板新增机器人运行比例，分别展示 WebSocket 连接与 Webhook 启用状态。

## 调整

- 前端更新为新版萌卡 NT 的界面风格，统一侧栏、标签栏、卡片、按钮、选择框和弹窗样式。
- 管理员菜单移至侧栏底部，手机保留快捷入口；手机主导航调整为浮动布局。
- 更新首页统计卡片、图表及登录页面，统一浅色、深色和各主题色的显示。
- 首页优先加载账号状态与收发概览，历史图表延后加载并减少重复读取；页面隐藏时暂停相关刷新。
- 主题色采用原地渐变，并兼容系统的减少动态效果设置。

## 修复

- 修复窄屏首页内容受网格最小宽度影响而横向裁切的问题。
- 修复小屏幕登录时验证码图片挤压输入框的问题。
- 修复手机侧栏关闭后仍可能被键盘聚焦，以及关闭账号设置弹窗后焦点落在不可见入口的问题。

## 升级说明

本版为纯框架更新，安装包不包含机器人配置、业务插件、插件数据、订阅、数据库或管理员凭据。现有业务插件无需随本次界面更新替换。

升级时替换框架程序与完整的 `web/dist`，保留原 `data` 目录及 `master.key`；同一数据目录只运行一个框架实例。升级后刷新浏览器即可加载新版界面。

继续使用 1.0.4 起的压缩消息格式，不要直接降级到 1.0.3 或更早版本，也不要用旧数据库覆盖升级后的新消息。数据保留设置继续沿用。
